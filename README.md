# DevilConnection-SubtitleTextDisplay
《でびるコネクショん》（Devil Connection / 恶魔连结）菜单中周目副标题显示。<br>
模组加载器：[a](https://github.com/shouennyou/DevilConnection_ModLoader)<br>
需要前置模组：简体中文 - 图片补丁 和 简体中文 - 文本补丁，请将这两个模组的加载顺序置于本模组之后。<br>
第一次做这种模组，不是很熟练，可能问题比较多

---

##  简介

在菜单界面显示周目的副标题，例如\~结局的探索\~。
在狂信徒线中，对应的提示字体会有不同。
